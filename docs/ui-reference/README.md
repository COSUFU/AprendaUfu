# Referência visual de UI

Frames extraídos do protótipo em vídeo (`Gravação de Tela 2026-08-11 181233.mp4`, gravação de
79s de um clique-a-clique pelo protótipo de UI) para servir de referência visual nas issues de
implementação — ver seção "Frontend" do template em
`.github/ISSUE_TEMPLATE/implementacao.md`.

O vídeo em si não faz parte do repositório (é grande e é só material de referência de design,
não um artefato do produto); os frames abaixo são os recortes relevantes.

RF27), resultado de busca (RF43) e edição de perfil (RF07) — o vídeo mostra o botão/entrada
mas não o fluxo completo. Issues desses requisitos não têm frame de referência; sinalizar isso
para quem for desenhar a tela.
